# License note: anthropics/skills

The upstream repository, https://github.com/anthropics/skills, has no repository-wide LICENSE file. Anthropic sets the license per skill: most skills (including docx, pdf, pptx, xlsx, skill-creator, mcp-builder and frontend-design) ship a `LICENSE.txt` inside their own folder. Skills Stack keeps those files in place, and each of those skills' `ATTRIBUTION.md` points to its file.

`doc-coauthoring` and `template-skill` have no license file upstream, so no license is stated for them. Treat them as all rights reserved by Anthropic, PBC unless Anthropic states otherwise.
