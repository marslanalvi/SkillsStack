# Notice

Skills Stack is a compilation of AI agent skills created by third parties and published by them under open-source and Creative Commons licenses. Skills Stack collects these skills, sorts them into categories, and packages them as installable plugins.

## Ownership

- Each skill remains the work of its original authors, who keep all copyright and other rights in it.
- Skills Stack does not claim ownership of any skill it collects, and nothing here transfers or changes the authors' rights.
- The license that applies to each skill is the license its authors chose. It is named in the skill's `ATTRIBUTION.md`. If the skill folder contains its own `LICENSE` file, that file applies.

## Credit and license texts

- Every skill folder contains an `ATTRIBUTION.md` naming the skill's creator, the project it came from, a link to the original, its license, and any changes Skills Stack made.
- The full license text and copyright notice of every upstream project is in [`licenses/`](licenses). Each plugin also carries the licenses for its own skills in its `LICENSES/` folder.
- [CREDITS.md](CREDITS.md) lists every project and individual author whose work is included.

## Changes

Skills Stack moves each skill into a category folder and adds an `ATTRIBUTION.md`. It does not otherwise change skills, except where noted in that skill's `ATTRIBUTION.md` (for example, fixing a link after a folder move).

## Skills with no stated license

Two skills collected from https://github.com/anthropics/skills, `doc-coauthoring` and `template-skill`, have no license file upstream. They are included with credit to Anthropic, PBC, and no license is granted for them by Skills Stack. They will be removed on request.

## No warranty

The skills are provided "as is", without warranty of any kind, as stated in their licenses. Review a skill before you run it, especially one that executes scripts or commands.

If you are an author and want your credit corrected or your work removed, open an issue at https://github.com/marslanalvi/SkillsStack/issues.
